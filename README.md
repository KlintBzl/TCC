# Sistema de Agendamento para Salão de Beleza

## Sobre o projeto

Este projeto consiste no desenvolvimento de um sistema web para gerenciamento de agendamentos de um salão de beleza.

A proposta surgiu a partir da dificuldade de organizar horários de atendimento utilizando métodos manuais, como cadernos, mensagens e anotações, que podem causar desorganização e conflitos de horários.

O sistema busca facilitar a organização dos clientes, dos serviços oferecidos e dos agendamentos, proporcionando uma maneira mais prática de gerenciar os atendimentos.

## Problema

A organização manual dos agendamentos pode dificultar a consulta dos horários disponíveis, causar esquecimentos, gerar agendamentos duplicados e tornar mais difícil administrar as informações dos clientes.

## Objetivo

Desenvolver um sistema web que facilite o gerenciamento dos agendamentos de um salão de beleza, permitindo organizar clientes, serviços e horários de atendimento.

## Funcionalidades previstas

- Cadastro de clientes.
- Consulta, edição e exclusão de clientes.
- Consulta, edição e exclusão de serviços.
- Cadastro e gerenciamento de agendamentos.
- Visualização dos agendamentos por dia e por semana.
- Prevenção de conflitos de horários.
